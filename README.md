这是《奶龙历险记》的重制工程。迁移包和旧单文件 HTML 位于本目录之外，只作为 `legacy` 参考，不会被新工程导入或继续修改。

## 当前阶段

阶段 0：技术边界和视觉方向确认。

- 已确定 Web 端 3D 技术方向与模块边界。
- 已建立世界内容包 TypeScript 契约草案。
- 已建立角色、场景、UI 和音频资产规范草案。

- 正式奶龙和洞洞幺模型尚未制作；必须先确认正、侧、背三视图。

## 目标结构

```text
nailong-adventure/
  docs/                       技术、资产和验收规范
  prototypes/                 用户确认用的视觉原型
  public/assets/              经确认的正式运行时资产
  src/
    core/                     渲染循环、资源、事件、性能
    gameplay/                 跑酷、碰撞、追逐、奖励、结算
    characters/               角色控制器与动画状态
    worlds/                   世界包接口与各世界配置
    lobby/                    次元驿站场景与交互
    ui/                       HUD、菜单、图标、动效
    save/                     版本化本地存档
    config/                   平衡和画质配置
  tests/
```
