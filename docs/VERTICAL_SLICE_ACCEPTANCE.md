## 阶段 B：可玩切片

- [ ] 从次元驿站进入世界，不刷新页面。
- [ ] 换道、跳跃、下滑输入响应一致，无穿模和重复触发。
- [ ] 碰撞有清晰前摇、反馈、短暂无敌与恢复。
- [ ] 相机在普通跑、加速、紧追和奖励段之间平滑切换。
- [ ] 洞洞幺能阶段性接近、回头、逃入传送门，但不会被永久抓住。
- [ ] 至少三种路线段、三种障碍和一个动态环境事件。
- [ ] 金币、分数、次元碎片、结算和一条故事线索完整闭环。
- [ ] 刷新浏览器后设置、货币和解锁状态仍可恢复。

## 视觉否决项

- 使用旧 OBJ/MTL 或程序几何体角色作为正式角色。
- 通用低模森林简单换色。
- emoji 图标、普通深色矩形菜单、缺乏按压和奖励状态的按钮。
- 障碍与背景同色，或者特效遮挡路线判断。
- 未确认三视图便大量制作角色动画或玩法内容。
